# Data Engineering Projects

Applied SQL projects that extend the learning lessons into portfolio-ready engineering work.

## Project Roadmap

### [1_EDA](../1_EDA/README.md) | Exploratory Data Analysis

Answers three market questions: demand, compensation, and practical skill priorities.

**Skills:** joins, aggregation, median statistics, filtering, logarithmic scoring.

### [2_WH_Mart_Build](2_WH_Mart_Build/README.md) | Warehouse and Analytical Marts

Builds reusable analytical tables from the normalized source model.

**Skills:** DDL, CTAS, dimensional modeling, idempotency, verification queries.

### [3_Flat_to_WH_Build](3_Flat_to_WH_Build/README.md) | Flat Data to Star Schema

Documents and implements the transformation pattern for a flat source with embedded skill lists.

**Skills:** parsing, deduplication, surrogate keys, bridge tables, referential checks.
